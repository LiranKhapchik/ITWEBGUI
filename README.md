# פורטל מחשוב ושליטה - מרכז שליטה צוות מחשוב

פורטל אינטרנט פנימי לניהול מרכז השליטה של צוות המחשוב. המערכת מרכזת את כלל הפעילויות של צוות המחשוב, לרבות פתיחה ומעקב אחר תקלות, ניהול מלאי סיריאלי מקיף, השאלת ציוד, שריון כיתות וחדרי דיונים, ניהול משמרות ותורנויות של הצוות, והפקת דוחות רשמיים בפורמט צבאי.

---

## 🚀 טכנולוגיות וארכיטקטורה

המערכת בנויה בארכיטקטורת Client-Server קלה ויעילה המותאמת להרצה בסביבות סגורות ומאובטחות:
- **צד לקוח (Client Side):**
  - **HTML5 & Vanilla JavaScript (ES6):** ניהול מצב (State Management) מקומי וסנכרון מול השרת.
  - **Tailwind CSS:** מיושם באמצעות ספריית JS מקומית לתמיכה מהירה בעיצוב מודרני מותאם אישית (כולל Dark Mode מלא).
  - **SheetJS (xlsx.full.min.js):** תמיכה מלאה בייצוא/ייבוא מדריכי תקלות מובנים מקובצי Excel (.xlsx).
- **צד שרת (Server Side):**
  - **PHP 8.1:** מנוע ה-REST API לניהול כלל בקשות המידע וסנכרון המצב.
  - **קובצי JSON:** שמירת הנתונים בקובצי JSON מקומיים תחת תיקיית `data/` המותאמים להרצה אופליין מלאה וקלה.
- **סביבת הרצה ופריסה:**
  - **Docker:** הרצה מבוססת אימג' Red Hat UBI 9 PHP 8.1, המותאם לעבודה כמשתמש שאינו root.
  - **OpenShift:** הגדרות מובנות לפריסה בקלאסטר הכוללות Persistent Volume Claim (PVC) לשמירת קובצי הנתונים, Service ו-Route מאובטח.

## 🛠️ הוראות הרצה ופריסה

### הרצה מקומית באמצעות Docker

ניתן להריץ את האתר בשתי דרכים מקומיות:

#### דרך א': באמצעות Docker Compose (מומלץ - שומר על הנתונים תיקיית data מקומית)
הרצו מתיקיית השורש:
```bash
docker compose up -d
```
האתר יהיה זמין בכתובת: `http://localhost:8080` והנתונים יישמרו בתיקיית `data` המקומית בפרויקט.

#### דרך ב': באמצעות פקודות Docker ישירות
1. **בניית ה-Image:**
   ```bash
   docker build -f docker/Dockerfile -t military-portal:latest .
   ```
2. **הרצת ה-Container:**
   ```bash
   docker run -d -p 8080:8080 --name military-portal-app military-portal:latest
   ```
   המערכת תהיה זמינה בדפדפן בכתובת: `http://localhost:8080`

### פריסה ב-OpenShift
הקובץ [openshift-deployment.yaml](file:///c:/Users/User/Desktop/ATAR%20MCHSUV/אתר/docker/openshift-deployment.yaml) כולל את כל הגדרות הפריסה הרשמיות. כדי לפרוס את המערכת בקלאסטר, הרץ:
```bash
oc apply -f docker/openshift-deployment.yaml
```
*הערה: התיקייה `/opt/app-root/src/data` ממופה ל-PVC בנפח 1Gi על מנת לשמור על קובצי ה-JSON קבועים ומוגנים מפני מחיקת פודים.*

  - **חשיפה בשלבים (Step-by-Step Wizard):** חשיפת כרטיסיות הטופס (פרטי פותח הקריאה -> מיקום ועמדה -> פרטי תקלה/בקשת שירות) בהתאמה למילוי תקין של השלבים הקודמים.
  - **פנאל סיכום והתקדמות צף:** הצגת כרטיס סיכום הבקשה והתקדמות פתיחת הקריאה בצד שמאל כאלמנט צף (`sticky top-6 self-start`) המלווה את המשתמש לאורך הגלילה.
  - **אריחי בקשות שירות מוגדלים בעיצוב אחיד:** הוספת אריחים בולטים עבור `בקשת שירות חומרה` ו-`בקשת שירות תוכנה` בצבעוניות אחידה ונקייה לצד תקלות חומרה, תוכנה וטלפוניה.
  - **אייקוני SVG מותאמים:** אייקון גלגל שיניים (`Gear`) לתקלות ובקשות שירות חומרה, ואייקון מסך CRT וינטג' לתקלות ובקשות שירות תוכנה.
- **שדרוג הדפסת שריון חדרים (`room-booking.html`):**
  - **הדפסת סמלים אמינה 100%:** טעינה אסינכרונית של סמלי חיל האוויר וחותם מיון חה"א ב-DOM לפני הפעלת דיאלוג ההדפסה, בשילוב כללי `-webkit-print-color-adjust: exact !important;`.
  - **שילוב חדרים במשימות גפיות:** אפשרות לשילוב מבנה וחדר ברישומי משימות גפיות (תאריך -- חייל -- משימה -- חדר).
- **ניהול משתמשים וזיהוי %USERNAME% בדשבורד (`dashboard.html`):**
  - עדכון שם הלשונית ל-"ניהול משתמשים" וגזירה אוטומטית של שם משתמש (בפורמט `s[ID]` או `nls_[ID]`) מהמספר האישי.
- **התאמה רספונסיבית נייטיבית וגמישה (Fluid Scaling):**
  - מפתח גודל ה-font הבסיסי הוגדר באופן נזיל (`clamp(14.5px, 1vw, 16px)`) השומר על הטקסט קריא, ברור וגדול בכל מסך.
  - הרכיבים והמכולות הראשיות הוגדרו בצורה יחסית ב-`vw` ו-`%` (`max-width: min(94vw, ...)`), כך שכלל האלמנטים מתכווצים ומתרחבים באופן יחסי לרזולוציית המסך תוך שמירה על גופנים קריאים ונוחים ב-100% Zoom.
- **ניגודיות תתי-כותרות במצב חשוך (Dark Mode):**
  - התווספו כללי High Contrast גלובליים ב-`style.css` המבטיחים שכל תתי-הכותרות, התיאורים והטקסטים המשניים בתוך כפתורים, אריחים וכרטיסים לחיצים ב-Dark Mode יישארו בולטים, חדשים וקריאים (`#cbd5e1` / `#e2e8f0` / `#ffffff`).
- **קובץ הרצה לבניית Docker ב-HTTPS (פורט 8001):**
  - נוצר קובץ הרצה אוטומטי `run-https.bat` בצירוף `docker-compose-https.yml`, `docker/nginx-ssl.conf` ו-`setup-ssl.ps1`.
  - מנהל חולל תעודת SSL מקומית, מריץ מכולת Nginx Proxy ב-HTTPS בפורט 8001, וממפה את תיקיית `data/` הפיזית לדיסק המחשב להבטחת שמירת נתונים מלאה ופציחה מפני הפסקות חשמל.
